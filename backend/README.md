## Introduction

In an era where human connections are increasingly mediated by technology, SparkDates aims to provide a platform where individuals can find love and companionship authentically. This README serves as a guide to understanding and contributing to the SparkDates project.

## Features

- **Registration and Authentication:** Secure registration with email verification.
- **User Profiles:** Detailed profiles with gender, interests, and photos.
- **Browsing and Searching:** Efficient search options based on location and interests.
- **Interaction:** Real-time chat and notifications for mutual matches.
- **Security:** Best practices for data encryption and protection against vulnerabilities.

## Project Structure

The project follows Clean Architecture principles, promoting scalability, maintainability, and testability by separating concerns into layers such as Presentation, Application, Domain, and Infrastructure.

## Setup Instructions

1. Clone the repository to your local machine.
2. Install dependencies using \`dotnet restore\`.
3. Configure the database connection string in \`appsettings.json\`.
4. Run database migrations using \`dotnet ef database update\`.
5. Build and run the application using \`dotnet run\`.

## Usage

1. Register as a new user and complete your profile.
2. Browse and search for potential matches.
3. Like profiles to initiate conversations.
4. Stay updated with notifications.
